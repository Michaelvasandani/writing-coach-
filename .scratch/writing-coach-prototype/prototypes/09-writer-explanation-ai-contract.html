When should the Coach change its mind?

This demo tests whether one structured reassessment contract can treat a Writer Explanation as scoped evidence, transparently withdraw, revise, or retain Suggestions, ask rather than guess when context conflicts, and preserve only anchors that still match the live article.

Proposed Coaching Contract

Request: evidence, scope, anchors, and reason for reassessment

        
Response: explicit outcomes plus questions and anchor decisions

        
Prompt guidance: the judgments the model must not blur together
1. Treat Writer input as evidence, not a command or an automatic exemption.
2. Apply passage context only to its anchored passage. Apply article context only when the Writer explicitly selected that scope.
3. For every candidate Suggestion, return exactly one outcome: retained, revised, withdrawn, or unchanged.
4. Retained and revised outcomes must explain why the concern survives the new evidence. Withdrawn outcomes must name what changed the judgment.
5. Reassess related Suggestions only when both issueKind and relevant context match. Otherwise return unchanged without silently reconsidering them.
6. If a material scope or applicability judgment is uncertain, ask one concrete Writer question. If contexts conflict, never choose one silently.
7. Validate block ID, exact quote, offsets, and revision before applying a response. A mismatch is stale: discard it and request fresh analysis.
8. A material passage edit retires context unless the same intentional choice is still evidenced. Deletion always retires passage context.
9. Never transfer context to a different Article. Never update Priorities or Draft Snapshot scores outside a requested fresh snapshot.

Decision this prototype is testing
Use one reassessment endpoint with a versioned request, candidate Suggestions, scoped Writer evidence, and live anchor data. Require an outcome for every candidate, explicit questions for material uncertainty or conflict, and deterministic client-side anchor validation before any model result changes state.
