Can the Draft Snapshot contract say only what the evidence supports?

This demo tests a structured AI response in which the model makes six evidence-anchored category judgments, while application code rejects stale or invented evidence and derives the overall score. It is intentionally not production code.

Decision being tested

Is this contract strict enough to produce consistent scores and useful explanations, yet expressive enough to withhold judgment on an early draft and treat an unconventional choice as a question about intent—not an automatic defect?

Proposed response shape

{ contractVersion: "draft-snapshot.v1", articleRevision: string, categories: [{ category: six-value enum, assessment: | { status: "scored", score: 1..5, confidence: "low" | "medium" | "high" } | { status: "insufficient", score: null, confidence: "insufficient" }, explanation: string, evidence: [{ blockId, start, end, quote }], intentQuestion: string | null }], priorities: [{ category, guidance, evidenceRefs }] // 0..3 } Application-derived, never model-authored: valid anchors, assessable count, overall score, provisional state

Prompt guidance under test

  1. Judge observed reader impact for the stated purpose and audience; never grade effort, talent, completeness, or convention-following.
  2. Use “insufficient” when repeated behavior cannot yet be observed. Never turn missing evidence into a low score.
  3. Support every score with exact article evidence and describe pattern → reader impact. Do not prescribe replacement prose.
  4. If a pattern may be intentional and intent is unknown, preserve the evidence-based score, lower confidence, and ask one neutral question.
  5. If intent is known, judge whether the choice achieves that intent. Keep any remaining reader friction visible.
  6. Return exactly one result for each category. Select no more than three high-impact priorities from scored categories only.
Why derive the overall score?

The model has no discretion to contradict its own categories. The application shows no overall score until at least four categories are assessable; otherwise it averages category scores and converts the result to 0–100. Any low-confidence category makes the result provisional.
