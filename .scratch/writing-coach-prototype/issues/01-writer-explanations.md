# Writer explanations that teach the coach

Type: grilling
Status: resolved
Assignee: Codex

## Question

How should a Writer Explanation change the current suggestion, related suggestions, and future coaching without causing the Coach to ignore genuine problems or permanently mislearn the writer's voice?

## Comments

### Resolution — 2026-09-12

Treat every Writer Explanation as evidence about the current Article, never as an instruction that automatically dismisses a problem or as knowledge that transfers to another Article. An explanation normally belongs to its passage; it becomes article-wide Coaching Context only when the Writer explicitly chooses or confirms that scope. Coaching Context is visible and editable, persists when the same Article is reopened, and is cleared when a different Article replaces it or the Writer clears the draft.

On receiving an explanation, the Coach must visibly reassess the current Suggestion as **withdrawn**, **revised**, or **retained**, explaining the new judgment. It may reconsider related Suggestions only when they share both the apparent issue and relevant context, and it must identify what it reconsidered. If applicability is uncertain and material, ask the Writer; otherwise leave the related Suggestion unchanged. Any conflict between explanations or Coaching Context also goes back to the Writer rather than being resolved automatically.

Intentionality changes the framing of coaching but does not silence evidence of a mismatch with the Writer's stated intent, audience, or facts. When the Writer knowingly accepts a tradeoff, suppress equivalent repeat Suggestions until the passage or surrounding evidence changes materially; the concern may still affect a later Draft Snapshot.

Editing, deleting, or invalidating context triggers selective reassessment of linked or plausibly affected passages. Deleted passages retire their passage-specific explanations; materially revised passages keep an explanation only when the same intentional choice still applies. Context changes mark the Draft Snapshot outdated, but a full snapshot is regenerated only when the Writer requests it. Scores and Priorities change only through that fresh assessment, never as automatic exemptions.
