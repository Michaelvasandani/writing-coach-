# Run the first informal Writer test round

Type: task
Status: open
Blocked by: 14

## Question

Have 5–8 Writers freely explore the integrated local prototype with a blank Article or their own 500–2,000-word general-audience draft, then capture the problems they report and the builder's direct observations so the next iteration decision has concrete evidence.

## Comments

### Writer-and-builder checklist

1. Invite 5–8 Writers who can try a blank Article or paste a general-audience blog draft of roughly 500–2,000 words.
2. Run the prototype locally with the builder present; let each Writer explore freely without a prescribed task sequence.
3. Ask Writers to report anything confusing, intrusive, unhelpful, ownership-reducing, or unexpectedly useful in their own words.
4. Record concise problem reports and direct observations here. Do not add a scoring rubric, formal interview script, instrumentation, or numerical success threshold.
5. When the round is complete, invoke Wayfinder with this ticket so the observations can be recorded and the resulting iteration decision can graduate from the map's fog.
